# Evaluador de Progreso en el Gimnasio

## Indicadores a revisar

### 1. Fuerza en ejercicios clave

Los mejores indicadores de retencion/ganancia muscular:

| Ejercicio | Tipo | Que indica |
|-----------|------|------------|
| Sentadilla | Compuesto inferior | Cuádriceps, glúteos |
| Peso muerto / RDL | Compuesto inferior | Cadena posterior |
| Press banca | Compuesto superior | Pecho, tríceps |
| Press hombros | Compuesto superior | Deltoides, tríceps |
| Dominadas/Jalon | Compuesto superior | Dorsal, bíceps |
| Remo | Compuesto superior | Espalda media |

**Interpretación:**
- Fuerza se mantiene o sube → **retienes/ganas músculo**
- Fuerza baja ligeramente respecto a la línea base → Puede ocurrir en un déficit; monitorear el contexto
- Fuerza cae de forma sostenida y relevante → **Posible señal de fatiga o pérdida muscular; revisar antes de ajustar**

### 2. Peso corporal (promedio semanal)

| Velocidad de pérdida | Interpretación |
|----------------------|----------------|
| Pérdida gradual | Puede ser compatible con recomposición; valorar respuesta individual |
| Pérdida rápida | Puede ser más exigente; vigilar fuerza, hambre y recuperación |
| Sin cambio 2-3 semanas | Posible estancamiento, ajustar calorías |
| Ganancia de peso | Revisar déficit calórico |

### 3. Mediciones corporales

Medir semanalmente en las mismas condiciones:
- **Cintura** (a la altura del ombligo): Debe bajar si pierdes grasa
- **Caderas**: Puede bajar
- **Brazos** (relajados y flexionados): Deben mantenerse o subir
- **Muslos**: Deben mantenerse
- **Pecho**: Debe mantenerse

**Buen indicador**: Cintura baja + brazos/muslos se mantienen = pierdes grasa, retienes músculo

### 4. Fotos de progreso (cada 4 semanas)

- Frente, lado y espalda
- Misma iluminacion, camara, angulo, hora, pose
- Comparar mes a mes (NO semana a semana — cambios muy sutiles)

### 5. Composición corporal

- **DEXA scan**: Gold standard (cada 2-3 meses)
- **Bioimpedancia**: Menos precisa pero util para tendencias (mismas condiciones siempre)

## Señales de alarma

### Estas perdiendo músculo si:
- Fuerza cae de forma sostenida en varios ejercicios y sesiones
- Pierdes peso muy rápido de forma sostenida y aparecen señales de fatiga
- Brazos y muslos se achican pero cintura no baja proporcionalmente
- Fatiga persistente que no mejora con descanso
- Pérdida de definicion muscular, zonas "blandas"

### Acciones correctivas:
1. **Reducir déficit** (subir 100-200 kcal)
2. **Asegurar proteína** (mínimo 1.8 g/kg, mejor 2.0-2.4 g/kg)
3. **Revisar sueño** (7-9 horas)
4. **Considerar diet break** (1-2 semanas a mantenimiento)
5. **Reducir cardio** si es excesivo
6. **Hacer deload** si no has hecho en 4+ semanas

```
- Inicio: XX.X kg | Actual: XX.X kg | Cambio: -X.X kg (-X.X%/sem)
- Velocidad: [OPTIMA / RAPIDA / LENTA / ESTANCADA]

FUERZA (ejercicios clave):
- Sentadilla: XX kg x X reps → XX kg x X reps [MANTIENE/SUBE/BAJA]
- Press banca: XX kg x X reps → XX kg x X reps [MANTIENE/SUBE/BAJA]
- Peso muerto: XX kg x X reps → XX kg x X reps [MANTIENE/SUBE/BAJA]

MEDICIONES:
- Cintura: XX cm → XX cm [BAJA/MANTIENE]
- Brazos: XX cm → XX cm [MANTIENE/SUBE]

VEREDICTO: [Recomposición exitosa / Ajustar déficit / Posible pérdida muscular]

ACCIONES RECOMENDADAS:
1. ...
2. ...
```

## Cuando ajustar el plan

| Situacion | Accion |
|-----------|--------|
| Fuerza sube + peso baja | Perfecto, no cambiar nada |
| Fuerza se mantiene y el peso baja gradualmente | Señal compatible con el objetivo, continuar y reevaluar |
| Peso no baja 2-3 semanas | Reducir 100-150 kcal o añadir 1 sesión LISS |
| Fuerza baja significativamente | Subir calorías 100-200 kcal, asegurar proteína y sueño |
| Peso baja demasiado rápido | Considerar subir calorías o reducir actividad según el contexto |
| Fatiga cronica | Deload inmediato + revisar sueño/estres |
