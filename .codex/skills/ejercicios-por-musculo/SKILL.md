# Selección de ejercicios

Parte del objetivo, ejercicio actual, equipo y tolerancia. Consulta solo el grupo pertinente del [catálogo de opciones](references/catalogo.md).

Las opciones comparten objetivos musculares, pero no son equivalentes en patrón, rango o demanda. Explica el compromiso de una sustitución y revisa carga, repeticiones y técnica; no copies el peso entre máquinas ni ofrezcas tres implementos por obligación.

Para técnica, usa [tecnica-ejercicios](../tecnica-ejercicios/SKILL.md). Ante dolor, usa [entrenar-con-lesiones](../entrenar-con-lesiones/SKILL.md); no declares una alternativa universalmente segura. El EMG no basta para elegir el ejercicio que producirá más hipertrofia.
