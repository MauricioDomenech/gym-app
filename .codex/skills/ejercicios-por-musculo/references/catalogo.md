# Catálogo de opciones por grupo

Usa solo las filas relevantes. Son opciones de selección, no sustituciones idénticas ni prescripciones de series y repeticiones. Comprueba equipo, patrón y tolerancia.

| Grupo / patrón | Máquina | Cable | Peso libre o corporal |
|----------------|---------|-------|-----------------------|
| Pecho / press | Press de pecho plano o inclinado | Press con cable | Press con barra o mancuernas; flexiones |
| Pecho / aducción | Pec deck | Aperturas con cable | Aperturas con mancuernas |
| Espalda / tracción vertical | Jalón o dominada asistida | Jalón | Dominadas o chin-ups |
| Espalda / tracción horizontal | Remo con apoyo | Remo sentado o unilateral | Remo con mancuerna o barra |
| Hombro / press | Press de hombros | Press con cable | Press con mancuernas o barra |
| Deltoides lateral | Elevación lateral en máquina | Elevación lateral con cable | Elevación lateral con mancuerna |
| Deltoides posterior | Reverse pec deck | Aperturas posteriores | Aperturas posteriores con mancuernas |
| Tríceps / extensión de codo | Extensión de tríceps | Pushdown o extensión overhead | Extensión con mancuerna o barra EZ |
| Bíceps / flexión de codo | Curl en máquina | Curl con polea | Curl con barra o mancuernas |
| Cuádriceps / sentadilla | Hack, Smith o belt squat | Sentadilla con cable si el equipo lo permite | Sentadilla o split squat |
| Cuádriceps / extensión de rodilla | Extensión de piernas | Extensión con tobillera y montaje adecuado | Reverse Nordic, si se tolera y domina |
| Isquiotibiales / bisagra | Variante de bisagra compatible con la máquina | RDL con cable o pull-through | RDL con barra o mancuernas |
| Isquiotibiales / flexión de rodilla | Curl sentado o tumbado | Curl con tobillera y montaje adecuado | Curl deslizante o Nordic asistido |
| Glúteos / extensión de cadera | Glute drive | Extensión de cadera con cable | Hip thrust o puente |
| Cadera / abducción | Abducción en máquina | Abducción con cable | Abducción con banda |
| Gemelos / flexión plantar | Elevación de pie o sentada | Sin equivalente necesario | Elevación con mancuerna o a peso corporal |
| Core / flexión de tronco | Crunch en máquina | Crunch con cable | Crunch controlado |
| Core / antirrotación | Sin equivalente necesario | Pallof press | Elegir otro patrón si no hay resistencia lateral adecuada |
| Core / anti-extensión | Sin equivalente necesario | Rollout con montaje adecuado | Plancha o rueda abdominal según capacidad |

## Diferencias que importan

Un curl predicador no reproduce la posición de hombro de un curl inclinado. Una rotación de torso no es antirrotación. Cambiar de una bisagra a un curl femoral cambia la función principal entrenada. No fuerces equivalentes para rellenar columnas ni asignes aislamientos anatómicos absolutos a ejercicios compuestos.
