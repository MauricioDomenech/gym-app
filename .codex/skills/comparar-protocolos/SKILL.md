# Comparador Justo de Protocolos

## Principio fundamental

**Rara vez hay un "mejor absoluto".** La mayoría de debates en fitness (PPL vs UL, keto vs balanced, HIIT vs LISS) son falsas dicotomías. La respuesta casi siempre es "depende del contexto".

---

## Framework de 6 dimensiones

Cada protocolo se evalua en 6 dimensiones con una escala de 1-5:

### 1. Evidencia de eficacia
- ¿Hay estudios comparando DIRECTAMENTE ambos protocolos?
- ¿Que tipo de estudios? (meta-análisis > RCT > observacional)
- ¿Cual es el effect size? (trivial < 0.2 | pequeño 0.2-0.5 | moderado 0.5-0.8 | grande > 0.8)
- Si no hay comparación directa: ¿hay evidencia mecanistica que sugiera superioridad?

### 2. Aplicabilidad a la población
- ¿Funciona para principiantes? ¿Intermedios? ¿Avanzados?
- ¿Funciona para hombres y mujeres?
- ¿Funciona para jóvenes y mayores?
- ¿Hay poblaciones para las que esta contraindicado?

### 3. Sostenibilidad (>12 semanas)
- ¿Se puede mantener a largo plazo?
- ¿Genera fatiga excesiva? ¿Relación insana con la comida/ejercicio?
- ¿Requiere restricciones sociales extremas?
- ¿Es compatible con una vida normal (trabajo, familia, social)?

### 4. Adherencia esperada
- ¿Es realista para humanos imperfectos?
- ¿Requiere mediciones imposiblemente precisas?
- ¿Es flexible ante imprevistos (viajes, enfermedad, estres)?
- La adherencia suele ser un determinante importante; no hay un predictor único que domine todos los contextos. El mejor plan es el que puedes seguir y evaluar.

### 5. Riesgos y efectos secundarios
- ¿Hay riesgo de lesión? ¿De deficiencia nutricional?
- ¿Hay riesgo psicológico (relación insana, TCA)?
- ¿Hay contraindicaciones médicas?
- ¿Cual es el peor escenario realista?

### 6. Contexto del usuario
- Fase actual (déficit, mantenimiento, superavit)
- Días disponibles para entrenar
- Equipamiento disponible
- Experiencia y preferencias
- Condiciones médicas

## Matriz de comparación estandarizada

```
COMPARACION: [Protocolo A] vs [Protocolo B]
============================================

Resultado medido: [Fuerza / Hipertrofia / VO2max / Composición corporal]
Nivel de evidencia: [Meta-análisis / RCTs / Observacional / Opinión]

| Dimension                | Protocolo A (1-5) | Protocolo B (1-5) | Notas |
|--------------------------|-------------------|-------------------|-------|
| 1. Evidencia de eficacia | /5                | /5                |       |
| 2. Aplicabilidad         | /5                | /5                |       |
| 3. Sostenibilidad        | /5                | /5                |       |
| 4. Adherencia            | /5                | /5                |       |
| 5. Riesgos               | /5 (5=bajo riesgo)| /5                |       |
| 6. Contexto usuario      | /5                | /5                |       |
| TOTAL                    | /30               | /30               |       |

VEREDICTO: [A superior / B superior / Equivalentes / Depende de X]
PARA QUIEN ES MEJOR A: [perfil de persona]
PARA QUIEN ES MEJOR B: [perfil de persona]
```

## Comparaciones pre-analizadas

### Splits de entrenamiento

#### PPL x2 (6 días) vs Upper/Lower (4 días)

| Dimension | PPL x2 | Upper/Lower | Notas |
|-----------|--------|-------------|-------|
| Evidencia | 4/5 | 4/5 | Ambos con frecuencia 2x/semana, hipertrofia similar |
| Aplicabilidad | 3/5 | 5/5 | PPL requiere 6 días, UL solo 4 |
| Sostenibilidad | 3/5 | 5/5 | PPL genera más fatiga acumulada |
| Adherencia | 3/5 | 4/5 | Más fácil comprometerse a 4 días |
| Riesgos | 3/5 | 4/5 | PPL puede sobrecargar hombros (push/pull frecuente) |
| **Veredicto** | Mejor si tienes 6 días y buena recuperación | Mejor para la mayoría de personas con vida ocupada |

#### Full Body (3 días) vs Upper/Lower (4 días)

| Dimension | Full Body x3 | Upper/Lower x2 | Notas |
|-----------|-------------|-----------------|-------|
| Evidencia | 4/5 | 4/5 | Frecuencia 3x vs 2x: meta diferencia mínima |
| Aplicabilidad | 5/5 | 4/5 | FB con solo 3 días, ideal principiantes |
| Sostenibilidad | 5/5 | 4/5 | Menos días = más sostenible |
| Adherencia | 5/5 | 4/5 | Menos compromiso semanal |
| Riesgos | 5/5 | 4/5 | Menor volumen por sesión, menos fatiga |
| **Veredicto** | Mejor para principiantes y personas con <4 días | Mejor para intermedios con 4 días disponibles |

---

### Protocolos de nutrición

#### Dieta keto vs Dieta balanceada (en déficit)

| Dimension | Keto | Balanceada | Notas |
|-----------|------|------------|-------|
| Evidencia | 3/5 | 5/5 | Meta-análisis: sin diferencia con calorías igualadas (Hall 2017) |
| Aplicabilidad | 2/5 | 5/5 | Keto no apta para todos (restricción severa) |
| Sostenibilidad | 2/5 | 5/5 | Keto difícil de mantener a largo plazo |
| Adherencia | 2/5 | 4/5 | Muchos abandonan keto por restricción social |
| Riesgos | 3/5 | 5/5 | Keto puede comprometer rendimiento en fuerza |
| **Veredicto** | Solo si el usuario la prefiere y adhiere | Superior para la mayoría de personas |

#### Ayuno intermitente 16:8 vs Comidas distribuidas

| Dimension | IF 16:8 | Distribuidas (4-5) | Notas |
|-----------|---------|---------------------|-------|
| Evidencia | 3/5 | 4/5 | Distribución de proteína ligeramente mejor para síntesis muscular |
| Aplicabilidad | 4/5 | 4/5 | Ambas adaptables |
| Sostenibilidad | 4/5 | 4/5 | IF más simple, distribuidas más flexibles |
| Adherencia | 4/5 | 4/5 | Depende de la persona |
| Riesgos | 3/5 | 4/5 | IF riesgo de atracones, difícil alcanzar proteína en ventana corta |
| **Veredicto** | Herramienta de adherencia, no superior per se. NO recomendado con historial de TCA |

---

### Protocolos de cardio

#### HIIT vs LISS (para pérdida de grasa)

| Dimension | HIIT | LISS | Notas |
|-----------|------|------|-------|
| Evidencia | 4/5 | 4/5 | Gasto calórico similar → resultados similares en composición corporal |
| Aplicabilidad | 3/5 | 5/5 | HIIT demandante, no apto para todos |
| Sostenibilidad | 3/5 | 5/5 | HIIT causa más fatiga, limita a 1-2x/semana |
| Adherencia | 3/5 | 4/5 | LISS más fácil de mantener |
| Riesgos | 2/5 | 5/5 | HIIT mayor riesgo lesión, interfiere con piernas |
| **Veredicto** | La proporción de LISS y HIIT depende de la tolerancia, la recuperación y el objetivo; no hay una combinación óptima universal. |

## Verificar honestidad de una comparación

Cuando alguien afirma "X es mejor que Y", verificar:

| Trampa | Pregunta clave |
|--------|---------------|
| Mejor caso de A vs peor caso de B | ¿Se estan comparando en igualdad de condiciones? |
| Variables no controladas | ¿Calorías, proteína, volumen son iguales? |
| Efecto novedad | ¿El resultado es porque es NUEVO, no porque es mejor? |
| Sesgo del autor | ¿Vende alguno de los dos protocolos? |
| Generalizacion | ¿El estudio es en la misma población que el usuario? |
| Tiempo insuficiente | ¿<4 semanas? Los resultados iniciales de cualquier cambio son engañosos |
| Outcome selectivo | ¿Se mide lo que importa o un proxy? |

---

## Regla de oro para comparaciones

> **Si ambos protocolos tienen evidencia razonable y el effect size es similar, la decisión se reduce a: ¿cual puede SEGUIR el usuario de forma consistente durante meses?**

La adherencia suele importar más que pequeñas diferencias teóricas entre protocolos cuando la evidencia es similar.
